# Быстрый старт локализации

## Что было сделано

✅ Создан middleware `SetLocale` для определения языка из URL  
✅ Обновлены роуты с поддержкой параметра `{locale}`  
✅ Созданы helper функции `view_locale()` и `route_locale()`  
✅ Создан компонент переключателя языка `<x-language-switcher />`  
✅ Настроена конфигурация (по умолчанию русский язык)

## Как это работает

### URL структура:
- `/ru/` - русская версия главной страницы
- `/uk/` - украинская версия главной страницы
- `/ka/` - грузинская версия главной страницы
- `/ru/about` - русская версия страницы "О нас"
- `/uk/about` - украинская версия страницы "О нас"
- `/ka/about` - грузинская версия страницы "О нас"

### Структура файлов:
```
resources/views/
├── home.blade.php          ← Оригинал (fallback)
├── home-ru.blade.php       ← Русская версия
├── home-uk.blade.php       ← Украинская версия
├── home-ka.blade.php       ← Грузинская версия
```

## Следующие шаги

### 1. Создайте локализованные версии страниц

Для каждой страницы создайте копии с суффиксами `-ru` и `-uk`:

```bash
# Пример для home.blade.php
cp resources/views/home.blade.php resources/views/home-ru.blade.php
cp resources/views/home.blade.php resources/views/home-uk.blade.php
cp resources/views/home.blade.php resources/views/home-ka.blade.php
```

### 2. Переведите контент

Откройте `home-uk.blade.php` и переведите весь текст на украинский.
Откройте `home-ka.blade.php` и переведите весь текст на грузинский.

### 3. Обновите ссылки в шаблонах

Замените все `route()` на `route_locale()`:

```blade
{{-- Было --}}
<a href="{{ route('about') }}">О нас</a>

{{-- Стало --}}
<a href="{{ route_locale('about') }}">Про нас</a>
```

### 4. Добавьте переключатель языка

В `header.blade.php` добавьте:

```blade
<x-language-switcher />
```

## Пример использования

### В роуте:
```php
Route::get('/about', function ($locale) {
    return view_locale('about');
})->name('about');
```

### В контроллере:
```php
public function index()
{
    return view_locale('home', ['data' => $data]);
}
```

### В Blade:
```blade
{{-- Генерация ссылки с текущей локалью --}}
<a href="{{ route_locale('home') }}">Главная</a>

{{-- Генерация ссылки с другой локалью --}}
<a href="{{ route_locale('home', [], 'uk') }}">Українська</a>
<a href="{{ route_locale('home', [], 'ka') }}">ქართული</a>

{{-- Переключатель языка --}}
<x-language-switcher />
```

## Приоритет перевода

1. **Высокий приоритет:**
   - `header.blade.php` / `footer.blade.php` (навигация)
   - `home.blade.php` (главная страница)
   - Формы заказов (`book-order/*`, `ebook-order/*`)

2. **Средний приоритет:**
   - Основные страницы (`about`, `acne`, `book`, `guide`)

3. **Низкий приоритет:**
   - Тест определения типа кожи (самый объемный)

## Важно!

- Всегда используйте `route_locale()` для внутренних ссылок
- Оригинальный файл (`home.blade.php`) остается как fallback
- Если локализованная версия не найдена, используется оригинал

## Тестирование

1. Откройте `/ru/` - должна открыться русская версия
2. Откройте `/uk/` - должна открыться украинская версия (или fallback, если файл не создан)
3. Откройте `/ka/` - должна открыться грузинская версия (или fallback, если файл не создан)
4. Проверьте переключатель языка - должен менять URL
5. Проверьте все внутренние ссылки - должны сохранять выбранный язык
